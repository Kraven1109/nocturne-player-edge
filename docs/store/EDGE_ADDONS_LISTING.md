## 2. Store Descriptions

### Short Description _(max 132 chars)_

Touch-first HTML5 video player: precision seek bar, gestures, quality/subtitles, night light, and optional dim/volume swipes.

### Detailed Description

```text
Nocturne Player for Edge turns any standard HTML5 <video> or direct video tab (.mp4/.webm, including local file:// files when "Allow access to file URLs" is enabled) into a touch-friendly full-screen player — with zero telemetry and zero network requests.

Key Features:
• Smart Auto-Hide Launcher Badge: stays out of your way while watching and wakes on pointer movement, touch, pause, or keyboard focus.
• Precision Seek Bar: drag smoothly to scrub directly on the main video (plus YouTube desktop & mobile chapter markers).
• Gesture Controls:
  - Double-tap left/right to jump ±10s; hold sides for 2x / stepped rewind.
  - Pinch to crop letterboxed black bars; swipe vertically on Shorts/Reels/TikTok feeds.
  - Optional Vertical Edge Gestures (turn on in Settings → Gestures): swipe left edge to dim video frames (10%–99% or drag past bottom for AUTO) and swipe right edge to adjust volume/mute.
• Quality, Audio Track, Speed & Loop Picker: switch resolution/audio tracks on YouTube, hls.js, dash.js, Shaka Player, and Playerjs, or toggle per-video loop in Settings.
• Local Subtitles & Night Light: load .srt/.vtt subtitle files and tune night light warmth, brightness, contrast, and saturation.
• Privacy First: runs 100% locally on your device. No analytics, no remote servers, unminified build.

Open-source (MPL-2.0). Independent Edge MV3 port of Nocturne Player by Vlad Pohorilets.
```

## 3. Permission & Certification Notes (For Edge Store Reviewers)

Copy this directly into the **Notes for Certification** box in Partner Center:

1. **Single Purpose:** Provides an enhanced touch/gesture-first overlay UI and playback controls for HTML5 `<video>` elements.
2. **`<all_urls>` content script match:** Required so the user can launch the player on any website containing a standard HTML5 `<video>` element (as well as YouTube and embedded players). Scripts only inspect `<video>` elements on the active page and never read cookies, form fields, or personal content. Users can disable the extension per-site in the popup.
3. **`world: "MAIN"` script (`pageagent.js`):** Bundled statically inside the extension package (no `eval`, no remote script loading, no external network calls). Uses a synchronous `CustomEvent` bridge (`nocturne:req` / `nocturne:res`) strictly to query existing client-side player objects already loaded by the page (quality ladders, subtitle/audio tracks, chapters, volume sync).
4. **`storage` & `activeTab`:**
   - `storage` (`storage.local` only, never `storage.sync`) saves local playback/appearance preferences and per-site disabled list strictly on-device.
   - `activeTab` lets the toolbar popup read the current tab hostname solely to toggle the extension on/off for that site.
5. **Test Instructions:** Build is unminified for inspection. Open any HTML5 video or YouTube watch page, hover over the video to reveal the Nocturne badge button, click to enter fullscreen overlay, and open Settings (top-right gear icon) to inspect Quality, Speed, Subtitles, and the optional Gestures toggle.
