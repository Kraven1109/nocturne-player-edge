# Plan: Session-Scoped Media Loop (`video.loop` & 1–N `loop.js` Facade) + `0x0` Audio-Only Guard

**Date:** 2026-11-16  
**Status:** Complete — Stage 3 & Stage 4 Verified (`139/139` Unit + Edge E2E)  
**Target Release:** `0.10.0`

## 1. Mục tiêu & So sánh Semantics

Phân định rõ 2 loại tùy chọn trong Nocturne Player:

- **Vertical swipe (Dim / Volume) (`isVerticalGesturesOn`):** **Thói quen điều khiển toàn cục** $\to$ **Persist** trong `settings.js` (`browser.storage.local`), mặc định `OFF`, bật 1 lần dùng xuyên suốt mọi video & mọi phiên sau.
- **Loop video:** **Trạng thái theo từng video / phiên xem (session-scoped)** $\to$ **Không persist** trong `settings.js`, mặc định giữ theo trang (`false`), `capture -> apply -> restore` khi thoát Nocturne để không làm video trang gốc lặp ngoài ý muốn, và **loại trừ** video feed dọc (`isFeedShaped() === true` như Shorts/Reels/TikTok) cũng như media `0x0` không có khung hình.

## 2. Kết quả Probe thực nghiệm (`[EMPIRICAL]` trên Edge `msedge`)

1. **YouTube Loop behavior (`_scratch/probe_loop_yt.mjs` & `_scratch/probe_yt_sabr_loop.mjs`):**
   - Video ngắn `jNQXAC9IVRw` (`19.02s`) với `video.loop = true`: timeline quay vòng `18.99 -> 0.34 -> ... -> 3.05`, `endedEvents: 0`, `paused: false`, `ytState: 1`, `urlOk: true` (không end-screen, không autoplay-next).
   - **YouTube Context-menu sync (`[EMPIRICAL]`):** Set mỗi `video.loop = true` làm `player.getLoopVideo()` trả về `true`, **nhưng** checkbox `"Loop"` trong context-menu của YouTube vẫn báo `aria-checked="false"`. Ngược lại, gọi `#movie_player.setLoopVideo(true)` đồng bộ **cả 3**: `video.loop === true`, `getLoopVideo() === true`, và `menuItemChecked === "true"`.
   - _Lưu ý SABR trên video dài:_ Trong môi trường headless tự động, cold-seek trực tiếp tới sát đuôi video 10–18 phút (`aircAruvnKk`/`aqz-KE-bpKQ`) bị throttle ở `ytState: 3` (buffering). Trên thực tế phát bình thường hoặc YouTube ngắn/local `file://`, `video.loop` + `setLoopVideo` đều xử lý đồng bộ sạch.
   - **Quyết định kiến trúc (`[DESIGN CHOICE]`):**
     - Core 1–N facade mặc định dùng native `video.loop = on` + bridge `setSiteLoop` (`op: 'setLoop'` gọi `setLoopVideo(on)` nếu `state.host` có — no-op trên `<video>` thường), vừa nhẹ vừa đồng bộ context-menu YouTube và giữ **đúng** thiết kế inject `{ isAllowed, apply, read }` cho bất kỳ nền tảng nào sau này mà **không sửa** `ui.js`/`menu.js`/`session.js`.
     - Giải thích trong code (`loop.js`): nền tảng thuần HTML5 chỉ cần property `video.loop` (khác với `seek`/`setVolume` vốn bắt buộc đụng API riêng để không sập stream); bridge `setLoop` chỉ là sync UI phụ trợ cho YouTube và hoàn toàn no-op trên host khác.
2. **Local `file://` MediaDocument (`test/fixtures/sample.mp4`, 120s):**
   - Set `video.loop = true`: đi qua `118.86 -> 119.32 -> 119.78 -> 0.16 -> 0.61 -> 1.07` (`endedEvents: 0`, `paused: false`).
3. **Audio-only `.mp4` degrade probe (`_scratch/audio_only.mp4` — `0x0`):**
   - **`[EMPIRICAL — Critical Catch]`:** Edge render `.mp4` chỉ có audio (`videoWidth: 0, videoHeight: 0`) thành `<video controls autoplay name="media">` có layout box mặc định **`300x150` (`>= 200x150`)**, khiến `isPlayable(video)` trong `detect.js` hiện tại trả về `true` (**`hasBadge: true`** dù không có hình!).
   - **Khắc phục bắt buộc trong `detect.js` (`isPlayable`):** Khi `video.readyState >= HAVE_METADATA && (video.videoWidth === 0 || video.videoHeight === 0)` thì trả về `false` $\Rightarrow$ degrade im lặng (`hasBadge: false`, 0 console error).
4. **Consumer `'ended'` scan (`src/`):**
   - `grep -rn "'ended'\|\"ended\"\|\.ended\b" src/` chỉ thấy `src/content/video/introwatch.js:123` (`!video.ended &&`), **không có** event listener `'ended'` nào trong toàn codebase.
